# v2.4.3 remediation release — 2026-07-30

## Purpose

v2.4.3 remediates the v2.4.2 external-review blockers in the passive provenance / review / rollup evidence pipeline.

This release does not authorize formal active rollout and does not itself close Phase 0. It makes the passive evidence-acceleration pipeline reliable enough to submit for external review.

## Implemented blockers

1. Missing provenance no longer contaminates `organic_live`.
   - Plugin `event_store.normalize_provenance()` returns `legacy_unclassified` for missing provenance.
   - Analyzer `classify_provenance()` / `provenance_info()` also buckets missing provenance as `legacy_unclassified`.

2. Invalid provenance no longer contaminates `organic_live`.
   - Plugin returns `unknown` for unsupported provenance strings.
   - Analyzer returns `unknown` and adds `invalid_provenance` anomaly.

3. Provenance is request-scoped when available.
   - `retriever._request_provenance()` reads `hook_context.capability_reuse_provenance` or `hook_context.provenance`.
   - Request-scoped provenance overrides `CAPABILITY_REUSE_PROVENANCE` env fallback.
   - Env fallback is marked with source `process_env`.

4. Event schema bumped.
   - `event_store.SCHEMA_VERSION = "1.1"`.

5. Review labels are durable across queue refreshes.
   - Analyzer loads existing `review/queue-latest.jsonl` and `review/queue-latest.csv` before refresh.
   - Existing `label`, `review_notes`, `reviewer`, and `reviewed_at` are preserved by stable event/review keys.

6. Rollups use event time, not run time.
   - `build_rollups()` now uses review-row event timestamps.
   - Rollups declare `window_basis: event_timestamp`.

7. CSV formula injection is neutralized.
   - CSV fields beginning with `=`, `+`, `-`, `@`, tab, CR, or LF are prefixed with an apostrophe.

8. Active multi-step uncovered HMP health prompts are rejected before intervention.
   - Retriever mutating/composite detection now rejects patterns like healthcheck + if down/investigate/fix/notify/ticket/escalate.

## Regression coverage

Added focused regressions in:

- `tests/test_batch_reuse_analyzer.py`
  - missing/invalid provenance bucketing;
  - CSV formula neutralization and label preservation;
  - event-time rollup windows.

- `tests/test_phase1b_active_healthcheck.py`
  - request-scoped provenance overrides env fallback and emits schema `1.1`;
  - uncovered multi-step health prompts do not intervene.

Full source tests now pass 57/57.
