## Pitfalls hit and fixed (do not repeat)

1. **Vacuous PASS**: first acceptance run wrote events via `mandatory()` directly (no `data` wrapper, no `event_type` top-level) → `fresh_events()` filter returned 0 → ratios `0/0` → VERDICT PASS. Fausto: never PASS on empty cohort. Fix: gate on `total_fresh >= 20`, use real `emit()` path.
2. **Relative import**: `from .v244_metadata import` in event_store.py → `ImportError` when run standalone. Fix: absolute import + `sys.path.insert(0, plugin_dir)`.
3. **Analyzer shape**: cohort/stream counts showed 0 right after PASS because analyzer read top-level `cohort_label` while emit() stores it inside `data`. Fix: normalize both shapes.
4. **Junk rows**: 25 rows from the broken first run (no `event_type`, has `deployment_id`) pollute events.jsonl; removed by filtering that pattern.
5. **Artifact internal version**: zip named v2.4.3 declared 2.4.1 inside; post-extract `sed` version fix needed on every target.
